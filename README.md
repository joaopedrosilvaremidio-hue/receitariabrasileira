# Receitaria

Sistema de receitas para iniciantes. Interface inicial em Next.js, com identidade visual preta, vermelha e branca.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Stack planejada
- Next.js + TypeScript + Tailwind CSS
- Supabase (autenticação e banco de dados)
- Cakto (assinaturas)
- Vercel (deploy)

> A integração com Supabase e Cakto ainda não foi configurada. Não há pagamentos reais nesta etapa.
